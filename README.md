# 🎸 Letreiro Vertical com Música – Geração Coca-Cola (Pygame)

Este projeto em Python utiliza a biblioteca **Pygame** para criar um letreiro vertical sincronizado com a música **"Geração Coca-Cola"** da banda Legião Urbana. O letreiro exibe a letra da música rolando na tela enquanto a trilha sonora toca, oferecendo uma experiência visual e sonora integrada.

---

## 🧠 Funcionalidades

- 🎵 Reprodução sincronizada de áudio e texto.
- ▶️ Botões interativos: **Play**, **Pause** e **Stop**.
- ⏱️ Temporizador sincronizado com pausa automática após **2 minutos e 18 segundos**.
- 🔠 Ajuste do tamanho da fonte via rolagem do mouse.
- 📜 Letreiro vertical com letra completa da música.

---

## 🛠️ Tecnologias utilizadas

- Python 3
- Pygame
- Bibliotecas padrão: `os`, `time`

---

## ▶️ Como executar

1. Certifique-se de ter o Python 3 instalado.
2. Instale o Pygame:
   ```bash
   pip install pygame
   ```
3. Coloque o arquivo `coca.mp3` na mesma pasta do script.
4. Execute o script:
   ```bash
   python letreiro_coca_cola.py
   ```
